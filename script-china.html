Regras Importantes
Siga sempre essas regras ao negociar
🔢

Quantidade sem ponto

Nunca use ponto para separar milhares. Chineses leem o ponto como decimal.

1.000 units
1000 units ✓
📋

Pedido sempre detalhado

Nunca diga "1000 de cada". Especifique modelo por modelo.

1000 of each
1000 for G001
1000 for G002 ✓
❌

Erro no pedido — cancele

Não peça para modificar. Cancele o pedido errado e faça um novo correto.

Please modify my order
Please cancel this order.
New order: ... ✓
👤

Nome para Western Union

Pergunte o primeiro nome e o segundo nome separadamente. Não use "sobrenome".

What is your first name?
What is your second name? ✓
📸

Sempre envie foto do modelo

Ao pedir agulhas e platinas, envie o modelo completo com foto para evitar erros.

Please see the photo.
I need this exact model. ✓

Agulhas para Tear
Scripts prontos para pedir agulhas
🇧🇷 O que você quer dizer
Eu preciso de agulhas para tear circular
🇨🇳 Script em inglês — copie e envie
Hello, I need needles for circular knitting machine. Please send me your catalog with models and prices. Thank you.
🇨🇳 Fazer pedido de agulhas — copie e envie
Hello, I would like to place an order for needles: 1000 for [MODEL CODE 1] 1000 for [MODEL CODE 2] 1000 for [MODEL CODE 3] Please confirm availability and total price. Thank you.
💡 Dica: Antes de fazer o pedido, envie sempre a foto do modelo da agulha que você precisa. Diga: "Please see the attached photo. I need this exact model."
⚙️
Platinas para Tear
Scripts prontos para pedir platinas
🇧🇷 O que você quer dizer
Eu preciso de platinas para tear circular
🇨🇳 Script em inglês — copie e envie
Hello, I need sinkers for circular knitting machine. Please send me your catalog with models and prices. Thank you.
🇨🇳 Fazer pedido de platinas — copie e envie
Hello, I would like to place an order for sinkers: 1000 for [MODEL CODE 1] 1000 for [MODEL CODE 2] 1000 for [MODEL CODE 3] Please confirm availability and total price. Thank you.
💡 Dica: Platinas em inglês técnico se chamam "sinkers". Sempre envie a foto do modelo junto com o pedido para evitar erros de modelo.
❌
Cancelar e Refazer Pedido
Nunca peça para modificar — sempre cancele e refaça
🇨🇳 Cancelar pedido — copie e envie
Hello, I need to cancel my previous order. Please do not process it. New correct order: 1000 for [MODEL CODE 1] 1000 for [MODEL CODE 2] Please confirm the cancellation and the new order. Thank you.
⚠️ Importante: Nunca use "Please modify my order". Chineses podem ignorar a modificação e enviar o pedido errado. Sempre cancele e faça um novo pedido do zero.
💵
Pagamento — Western Union
Como pedir os dados de pagamento corretamente
🇨🇳 Pedir dados para Western Union — copie e envie
Hello, I will pay via Western Union. Please provide your information: - What is your first name? - What is your second name? - What is your country? - What is your city? Thank you.
💡 Dica: Pergunte sempre "first name" e "second name" separadamente. Nunca use "last name" ou "sobrenome" pois pode gerar confusão com nomes chineses.
📋
Outros Scripts Úteis
Frases para situações do dia a dia
🇨🇳 Pedir catálogo e preços
Hello, Please send me your full catalog with prices and minimum order quantity (MOQ). Thank you.
🇨🇳 Pedir desconto
Hello, Can you offer a better price? I am a regular buyer and I plan to order frequently. Thank you.

Hello, Please confirm my order is ready. What is the shipping date? Please send me the tracking number when shipped. Thank you.
🇨🇳 Enviar foto do modelo
Hello, Please see the attached photo. I need this exact model. Do you have it in stock? What is the price for 1000 units? Thank you.
